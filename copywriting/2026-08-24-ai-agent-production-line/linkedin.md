### FINAL 文案（連結放留言版 — 建議用呢個）

2025 年我裝咗一大堆 AI 工具，結果全公司最忙嗰個係我自己。

每個工具都要我逐個溝通、逐個追進度；A 嘅 output 我自己搬去 B，中間甩漏又係我執。

問題唔係 prompt 唔夠精準，係我從來冇定義過：上一步做完，點交畀下一步。

連鎖店去到邊間分店味道都差唔多，唔係因為間間都有天才大廚，而係每道工序、每個驗收點一早定義好。要複製嘅唔係個人，係佢做嘢嘅方法。

於是我改成一個「總指揮」：拆步驟 → 派畀唔同 agent → 做完收貨 → 未過標準退返重做。

跑落嚟，有三點同我預期唔同：

→ AI 第一步唔係創作，係採樣。先定範圍再設門檻（同個帳號自己平時表現比，5 倍起跳，太多就收窄到 10 倍），批量整成一張表一齊比較。我最後揀嘅唔係邊條片嘅情節，係佢嘅創作條件。市場證據唔係創作答案。

→ 交接要有規格。角色、秒數、動作、音樂、乜嘢一定唔可以出現，全部要寫低。啲判斷留喺自己個腦、或者留喺上一個 chat 入面，下一步根本接唔到。

→ 自動化最緊要唔係冇人，係去到關口一定要有人閂。生成影片會燒 credit，AI 要先報今次使幾多，批唔批由人話事；出完仲要 QC。

條 Reel 後來喺 Facebook 跑到 62K views。但要講清楚：條生產線只證明到套系統真係生產得出一條片，唔代表生產線令佢爆 —— 爆唔爆仲有演算法、出街時機、觀眾反應。

最令我覺得呢套嘢有價值嘅一點：系統做完會回頭挑戰返我一開始嘅假設。搵咗 12 條同類片做對照，結果證明我原本兩個解釋都唔立得住腳，然後將修正咗嘅結論寫返入 workflow —— 下條片就唔會再用錯嗰個假設。

AI 做 execution，人做 judgment。

### FINAL post (link in first comment — recommended)

In 2025 I had a stack of AI tools, and I was still the busiest person in my own company.

Every tool needed briefing. Every output got carried by hand into the next tool. Every gap in between was mine to patch.

The problem was never prompt precision. I had never defined how one step hands off to the next.

A chain restaurant tastes the same in every branch not because every branch has a genius chef, but because every step and every checkpoint was defined in advance. What gets replicated is not the person — it's the method.

So I rebuilt around an orchestrator: break the work into steps → assign each step to a different agent → inspect what comes back → send it back when it misses the standard.

Three things ran against my expectations:

→ The first job for AI is not creation, it's sampling. Define the scope, set a threshold (5x an account's own normal performance, tightened to 10x when the list runs long), then compare the whole batch in one table. What I picked in the end was not a storyline — it was a set of creative conditions. Market evidence is not the creative answer.

→ Handoffs need a spec. Character, seconds, motion, music, and what must never appear. Judgment that lives in my head or in the last chat window cannot be picked up by the next step.

→ The point of automation is not removing people. It's putting a person at the gate. Video generation burns credits, so the system reports the cost first and a human approves it — and QC still happens after.

The Reel later did 62K views on Facebook. To be straight about it: the pipeline only proves the system can produce the video. It does not prove the pipeline made it perform — algorithm, timing and audience reaction are outside my control.

What actually convinced me it was worth building: after the run, the system went back and challenged my own opening assumption. It pulled 12 comparable videos, showed both of my explanations were unsupported, and wrote the corrected conclusion back into the workflow — so the next video does not start from the same mistake.

AI does execution. People do judgment.

If you've installed a lot of AI tools and you're still the busiest PM in your own company: can your method be broken into assign → hand off → inspect → send back → pass only when it clears?

Just posted a new video on how I run short-form video through an AI agent production line this year.

Same work that took me ages in 2025. Roughly 20x faster now, and the Reel it produced hit 62K views on Facebook.
