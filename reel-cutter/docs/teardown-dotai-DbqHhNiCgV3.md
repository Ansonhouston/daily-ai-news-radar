## 4. Hook 三重奏（0:00–0:03）

1. **視覺**：唔用人面，直接高速 scroll 複雜 AI dashboard → 「呢個人真係有系統」
2. **文字**：白字黑邊置中大字，第 1 秒出「已經進入咗」——**完成時態**，暗示你未跟上
3. **聲音**：Upbeat synth + 高能量 VO，零鋪墊寒暄

🔑 **機制 = 身份焦慮（Identity Gap），唔係好奇心（Curiosity Gap）。** 唔係問「你知唔知？」，係斷言「時代已變，你仲喺舊嗰邊」。對 B2B／專業觀眾比 curiosity hook 狠好多。

## 6. 核心論證：AI Agent 點解令 Marketers 成功

### 三宗罪 → 三個補位

| Level 1 缺口（0:13–0:20） | 本質 | Level 2 補位（0:24–0:47） |
|---|---|---|
| 冇好好睇你公司嘅資料 | **冇 Context** | 品牌知識庫（風格／定位／產品／平台規則） |
| 跟唔到你工作流程同 Skill | **冇 Procedure** | Workflow + Skill 明文化，每步調用 |
| 冇自主能力跑晒 Campaign | **冇 Agency** | 一個清晰目標 → 自己跑 Research／內容／API／CRM |
| （隱含）出唔到行動 | **冇 Tool Access** | 接駁 API：Sheets / Mailchimp / 報名表 / Email |

### 公式

> **Context ＋ Procedure ＋ Agency ＋ Tool Access ＝ 由「問答」變「交付」**

轉折點唔係 AI 變聰明，係 AI 由「回答你」變「幫你交貨」。省嘅唔係打字時間，係**串接時間** —— 而串接佔一個 marketer 一日 70% 以上。

### 三層槓桿階梯

| Level | 身份 | 槓桿來源 | 倍數 |
|---|---|---|---|
| 1 | 執行者 | 自己雙手 + AI 輔助打字 | 1X–1.5X |
| 2 | 管理者 | 一個人帶一隊 Agent（0:48） | **10X** — 槓桿嚟自**並行** |
| 3 | 建造者 | Workflow/Skill 變全團隊可用系統（1:07–1:11） | **100X** — 槓桿嚟自**複製** |

🔑 1→2 係**加人手**，2→3 係**加乘數**。片中冇明講，但命名體系已藏咗答案。講出嚟就係增值位。

### 對手完全冇碰、可以做差異化嘅四點

1. **回頭路／校準機制** — Agent 做錯點算？只有一張「自我改善 Loop」圖。真實跑法：Agent 出草 → 人審關鍵節點 → 錯嘅寫返入規則庫。
2. **知識庫門檻** — 「87 files」冇講由 0 到 87 要幾耐。實話：**先寫 3 個檔**（品牌語氣、產品事實、平台禁區）已有 80% 效果。
3. **邊啲工作唔應該交** — 片中暗示愈多愈好。真相：**判斷類唔交**（定位、取捨、談合作），只交**串接類 + 產出類**。
4. **失敗成本** — Agent 自主跑 Email/CRM 出錯係**對外**嘅。真實系統一定有 human-in-the-loop 卡喺對外動作前。片中零提及。
