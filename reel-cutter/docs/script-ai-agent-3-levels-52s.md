## 逐字稿

### S1　0.0–4.0s　Hook — 點名稻草人 + 身份焦慮
> 你仲係用 ChatGPT / **一問一答** 做 Marketing？/ 呢個做法，**落後咗一個世代**。

- 字幕（置中大字）：`你仲係一問一答做 Marketing？`
- 畫面：真人半身直望鏡頭，中景，手持微晃；第 3 秒切錄屏 ChatGPT 對話框
- 聲：3.2 秒一下 impact

### S2　4.0–7.0s　時代宣告 + 在場證明
> 而家**真正跑得起**嘅，係 AI Agent。/ 我自己日日咁跑。

- 字幕（底部）：`而家真正跑得起嘅係 AI Agent`
- 畫面：高速錄屏，你自己 Claude Code / Agent dashboard 連續 scroll
- 聲：whoosh

### S3　7.0–10.0s　3 個承諾（唔要 4）
> 三樣嘢：/ Agent 自己跑 Research、/ 自己出 Post、/ 自己入 CRM。

- 字幕（底部）：`① 自己跑 Research　② 自己出 Post　③ 自己入 CRM`
- 畫面：3 宮格，每格 1 秒逐格彈出
- 聲：3 下 beat sync

### S4　10.0–17.0s　三宗罪（診斷）
> ChatGPT 唔 work，**唔係因為佢笨**。/ 係三件事：/ 唔識你公司資料、/ 跟唔到你工作流程、/ 冇能力自己跑完一個 Campaign。

- 字幕（底部，三行）：
  `① 唔識你公司資料` / `② 跟唔到你工作流程` / `③ 跑唔完成個 Campaign`
- 畫面：對比 slide，三行逐行點亮打紅剔；底層放模糊嘅 ChatGPT 對話錄屏
- 聲：每行一下 tick

### S5　17.0–22.0s　⚡ 二次 Hook（對手完全冇）
> 但係 / **九成人搞錯順序**。/ 一開始就搭 workflow，/ 其實要**先寫知識庫**。

- 字幕（置中大字）：`九成人搞錯順序`
- 畫面：全屏紅底白字硬切 0.6 秒 → 切錄屏一個空 workflow canvas
- 聲：riser + impact（全片最大聲一下）

### S6　22.0–29.0s　公式：四件事
> Agent 要成事，只需四樣：/ 知識庫俾佢 **Context**、/ Skill 俾佢**步驟**、/ 一個清晰目標俾佢**自主**、/ API 俾佢**真係做得到嘢**。

- 字幕（底部，四行）：
  `知識庫 = Context` / `Skill = 步驟` / `清晰目標 = 自主` / `API = 做得到嘢`
- 畫面：四塊卡逐塊砌埋一齊成一個方格，每句對應一塊
- 聲：每塊一下 click

### S7　29.0–36.5s　真實鏈條演示（可信度核心）
> 我俾佢**一句目標**，/ 佢自己搵市場訊號、/ 自己寫成 Post、/ 自己填報名表、/ 自己 send 跟進 email。/ 我全程**只做審稿**。

- 字幕（底部）：`我只出一句目標` / `佢自己跑完成條鏈`
- 畫面：真錄屏連拍 — prompt 輸入 → research 輸出 → Post 草稿 → Google Sheet 入行 → Mailchimp send，每段 1.5 秒
- 聲：keyboard + 每步一下 pop
- ⚠️ 呢段係全片可信度支柱，一定要用**真錄屏**，唔好用 mockup

### S8　36.5–39.5s　高潮句
> 到呢一步，/ 你就係**一個人帶一隊 Agent**。

- 字幕（置中大字）：`一個人　＝　一隊 Agent`
- 畫面：節點圖，中間一個你，外圍六個 Agent 節點逐個連線著燈
- 聲：音樂短暫抽走 0.3 秒再入（留白 = 呢句最重）

### S9　39.5–44.5s　⚡ 差異化：兩樣唔好交（對手完全冇）
> 但有兩樣嘢，/ **千萬唔好**交俾佢：/ 定位同取捨。/ 判斷留俾自己，/ 串接才交 Agent。

- 字幕（底部）：`判斷 → 留俾自己` / `串接 → 交俾 Agent`
- 畫面：一分為二嘅圖，左邊「人」右邊「Agent」，兩個 icon 各自歸邊
- 聲：兩下 thud

### S10　44.5–48.0s　三層身份階梯
> 自己做係 **1X**，/ 帶一隊係 **10X**，/ 做到全公司都用得，/ 就係 **100X**。

- 字幕（底部）：`1X 執行者 → 10X 管理者 → 100X 建造者`
- 畫面：三級樓梯逐級升，數字由 1X 跳 10X 跳 100X
- 聲：三下升調

### S11　48.0–50.5s　CTA

## CTA 設定注意

對手用單字 `100X` 做 ManyChat trigger。本稿改用完整詞組 **`我要 Agent 攻略`**：

- 單字容易被其他 post 嘅留言誤觸，亦攞唔到上下文
- 完整詞組打得出＝意圖強，DM 開啟率同轉化都高
- DM 第一句要**覆述佢留咗咩**，第二句先出 link
